# ☕ Repositório de Projetos Java

Bem-vindo ao meu repositório de projetos em **Java**! 

Este espaço foi criado com o objetivo de consolidar e colocar em prática todos os conceitos e componentes da linguagem Java. Aqui, você encontrará uma coleção de aplicações e sistemas variados que desenvolvi para explorar desde os fundamentos da linguagem até recursos avançados e arquiteturas modernas.

## 🎯 Objetivos do Repositório

- **Praticar Programação Orientada a Objetos (POO):** Classes, Herança, Polimorfismo, Encapsulamento e Abstração.
- **Explorar Estruturas de Dados:** Uso de Collections modernas (Lists, Sets, Maps).
- **Aplicar Recursos Funcionais:** Utilização de Lambdas, Streams API e Optionals.
- **Manipulação de Dados:** Operações de Entrada/Saída (File I/O), leitura e escrita de arquivos.
- **Boas Práticas:** Código limpo, tratamento de exceções (Exception Handling) e design patterns básicos.

## 📁 Projetos Desenvolvidos

Abaixo está a lista dos projetos contidos neste repositório. Cada pasta possui seu próprio contexto e desafios específicos.

### 1. [DataFlow Finance (CLI)](./src/ProjetoFinanceiroJava)
Um processador e gerenciador de transações financeiras via linha de comando (CLI). O sistema lê lotes de transações de arquivos locais, valida os dados, aplica regras de negócio usando conceitos avançados de Orientação a Objetos e estruturas de dados, e exporta um relatório financeiro consolidado.
* **Conceitos abordados:** File I/O, OOP, Lambdas, Optionals, e manipulação de coleções.
